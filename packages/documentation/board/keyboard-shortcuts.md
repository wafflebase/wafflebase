# Keyboard shortcuts

Every keyboard shortcut on a board, for tools, sticky notes, navigation, selection, editing, and collaboration.

**Conventions.** Each entry lists the Mac key first, then Windows and Linux. To see the list in the app, press `⌘+/` / `Ctrl+/` on a board.

**Single-key tools** such as `S`, `T`, `M`, `/`, and `E` work only when nothing is selected and you can edit the board. With an item selected, typing a letter starts editing that item instead.

## Most used

| To do this | Press |
|---|---|
| Select tool | `V` or `Escape` |
| Add a sticky note | `S` |
| Finish a sticky note and start the next | `Tab` or `⌘+Enter` / `Ctrl+Enter` while typing |
| Add a text box | `T` |
| Zoom to fit the whole board | `Shift+1` |
| Find on the board | `⌘+F` / `Ctrl+F` |
| Undo | `⌘+Z` / `Ctrl+Z` |
| Redo | `⌘+Shift+Z` / `Ctrl+Shift+Z` |
| Show keyboard shortcuts | `⌘+/` / `Ctrl+/` |

## Navigation

| To do this | Press |
|---|---|
| Pan | Hold `Space` and drag |
| Hand tool (drag to pan) | `H` |
| Pan sideways | Hold `Shift` and scroll |
| Zoom at the pointer | Hold `⌘` / `Ctrl` and scroll or pinch |
| Zoom in | `⌘+=` / `Ctrl+=` |
| Zoom out | `⌘+-` / `Ctrl+-` |
| Zoom to 100% | `⌘+0` / `Ctrl+0` |
| Zoom to fit | `Shift+1` |
| Zoom to selection | `Shift+2` |
| Find on the board | `⌘+F` / `Ctrl+F` |
| Next or previous match in find | `Enter` or `Shift+Enter` |
| Stop following a teammate | `Escape` |

## Selection

| To do this | Press |
|---|---|
| Select everything | `⌘+A` / `Ctrl+A` |
| Lasso select | Hold `Option` / `Alt` and drag a loop on empty canvas |
| Clear the selection | `Escape` |
| Nudge 1 pixel | `←` `→` `↑` `↓` |
| Nudge 10 pixels | `Shift+←` `Shift+→` `Shift+↑` `Shift+↓` |

## Editing

| To do this | Press |
|---|---|
| Edit the selected sticky note, shape, or text | `Enter` or `F2` |
| Finish editing text | `Escape` |
| Add a sticky note next to the selected one | `⌘+Enter` / `Ctrl+Enter` |
| Paste text as sticky notes, one per line or cell | `⌘+V` / `Ctrl+V` |
| Copy | `⌘+C` / `Ctrl+C` |
| Cut | `⌘+X` / `Ctrl+X` |
| Paste | `⌘+V` / `Ctrl+V` |
| Duplicate | `⌘+D` / `Ctrl+D` |
| Delete | `Delete` or `Backspace` |

## Formatting

These work while you edit text.

| To do this | Press |
|---|---|
| Bold | `⌘+B` / `Ctrl+B` |
| Italic | `⌘+I` / `Ctrl+I` |
| Underline | `⌘+U` / `Ctrl+U` |
| Insert link | `⌘+K` / `Ctrl+K` |

## Objects

| To do this | Press |
|---|---|
| Sticky note | `S` |
| Text box | `T` |
| Section (drag, or click for a default size) | `Shift+S` |
| Rectangle | `R` |
| Ellipse | `O` |
| Line | `L` |
| Arrow | `Shift+L` |
| Connector | `X` |
| Marker (stays on until `Escape`) | `M` |
| Highlighter | `Shift+M` |
| Eraser (drag across strokes) | `Shift+E` |
| Draw a straight line | Hold `Shift` while drawing |
| Laser pointer | `Shift+K` |
| Group | `⌘+Option+G` / `Ctrl+Alt+G` |
| Ungroup | `⌘+Shift+Option+G` / `Ctrl+Shift+Alt+G` |
| Bring forward | `⌘+↑` / `Ctrl+↑` |
| Send backward | `⌘+↓` / `Ctrl+↓` |
| Bring to front | `⌘+Shift+↑` / `Ctrl+Shift+↑` |
| Send to back | `⌘+Shift+↓` / `Ctrl+Shift+↓` |
| Tidy up into a grid (two or more items) | `Option+Shift+T` / `Alt+Shift+T` |

## Collaboration

| To do this | Press |
|---|---|
| Comment on the selection, or click to place one | `⌘+Option+M` / `Ctrl+Alt+M` |
| Cursor chat | `/` |
| Emotes | `E`, then `1` to `6` to send |
