# Run a retro on a board

Run a Start, Stop, Continue retrospective on a board, from the template to a voted list of action items and a PDF. It takes about 15 minutes, and you learn the board's core tools on the way.

::: info Before you start
- You need a workspace where you can create documents.
- Teammates are optional. You can follow every step alone.
:::

## 1. Start from the Retro template

1. In your workspace, click **New**, then select **New from template**.
2. Open the **Public gallery** tab.
3. Find **Retro (Start / Stop / Continue)** and click **Use**.

The board opens with a title and four sections: **Start**, **Stop**, **Continue**, and **Action items**. Each section has a prompt sticky note and an empty one.

If your gallery has no Retro template, create a board with **New > New board** and add three sections named Start, Stop, and Continue. See [Sections](/board/sections#create-a-section).

![Retro board fresh from the template with Start, Stop, Continue, and Action items sections](/images/board/run-a-retro-template.png)

## 2. Invite your team

1. Click **Share** in the top right.
2. Invite teammates or copy a link with editor access. See [Share a document](/collaborate/share).

When teammates join, you see their cursors and avatars.

## 3. Add sticky notes

1. Double-click the empty sticky note in **Start** and type `Demo every Friday`.
2. Press `Tab`. A new green sticky note opens to the right. Type `Write release notes earlier`.
3. Press `Escape` to finish.
4. If a note lands outside the section, drag it in. A note belongs to a section once most of it is inside.

To add several at once, copy this list, click empty canvas, and press `⌘+V` / `Ctrl+V`. Each line becomes a sticky note. Drag them into **Stop**.

```text
Long stand-ups
Last-minute scope changes
Reviews waiting overnight
```

## 4. Group the duplicates

1. Drag sticky notes that say the same thing next to each other.
2. Select the notes in one section: click the first, then `Shift`-click the others.
3. Click **Arrange** in the top toolbar and select **Tidy up**.

The notes line up in an even grid.

## 5. Time-box the discussion

1. Click **Timer** (the stopwatch icon) in the top toolbar.
2. Set **Minutes** to `5` and click **Start**.

Everyone sees the countdown in the top-left corner of the canvas.

## 6. Vote on what to act on

1. In the tool dock, click the arrow next to the stamp button and select **Start voting…**.
2. Type `What should we act on first?`, keep **Votes per person** at 3, and click **Start**.
3. Click three sticky notes to vote on them. Click your own dot to take a vote back.
4. Click **Done**.
5. When everyone is done, click **End voting**.

The **Results** card ranks the notes by votes. Click a row to jump to that note.

![Voting card reading "What should we act on first?" with 2 of 3 votes left, and a vote dot on one sticky note](/images/board/run-a-retro-voting.png)

## 7. Write the action items

1. In **Action items**, double-click the sticky note **Action, owner, due date** and replace the text with `Demo every Friday, Alice, May 30`.
2. Press `Tab` to add the next action, and `Escape` when you finish.
3. Click **Clear results** on the **Results** card when you no longer need it.

## 8. Download the result

1. Click **Download** (the download icon) in the top-right corner of the canvas.
2. Select **Download as PDF**.

The PDF has the whole board on one page. Your board should look like this:

![Finished retro board with stickies in Start, Stop, and Continue, tidied into grids, and two action items](/images/board/run-a-retro-final.png)
