# Organize documents in folders

Folders group a workspace's documents so they're easier to find. Any document type can go in a folder, and folders can nest to any depth.

Folders only organize. They don't change who can open a document: every member of the workspace can open everything in it.

::: info Before you start
- Any member can create and rename folders, and rename or copy documents.
- To move or delete a folder or document, you need to have created it, or own the workspace.
- Folders exist inside one workspace. Open a workspace's documents list to use them.
:::

## Create a folder

1. Open the workspace's documents list, or the folder you want the new folder in.
2. Click **New** > **New folder**.
3. Enter a **Name** and click **Create**.

The folder appears in the list. To build a structure such as `Team` > `Projects` > `2026`, open each folder and create the next one inside it.

## Open a folder

1. Click a folder in the list to see what's inside.
2. To go back up, click a folder name in the breadcrumb at the top of the list. **Home** is the top level of the workspace.

![Documents list inside a nested folder with the Home / Team / Projects breadcrumb](/images/collaborate/folders-breadcrumb.png)

## Move documents into a folder

1. Select the documents with the checkboxes. `Shift`-click to select a range.
2. Drag the selection onto a folder in the list, or onto a folder name in the breadcrumb.

The documents move to that folder.

### Move with a dialog

1. Click **⋯** at the end of a document's row and select **Move to...**. For several documents, select them and click **Move to…** in the bar above the list.
2. Choose a **Workspace** and a **Folder**. **Home** is the top of the workspace.
3. Click **Move**.

The dialog is also how you move a document to another workspace you belong to.

![Move dialog with Workspace and Folder menus, the Folder menu open on the workspace's folders](/images/collaborate/folders-move-dialog.png)

## Move a folder

1. Click **⋯** at the end of the folder's row and select **Move to...**.
2. Choose the destination **Folder** and click **Move**.

Everything inside moves with it. A folder can't move to another workspace; if you choose one, only the documents in your selection move.

## Rename a folder or document

1. Click **⋯** at the end of the row and select **Rename**.
2. Enter the new name and click **Rename**.

You can also rename a document from inside it by clicking its title in the header. See [Edit together](/collaborate/edit-together#rename-a-document).

## Make a copy of a document

1. Click **⋯** at the end of the document's row. For several documents, select them instead.
2. Select **Make a copy**, or click **Make a copy** in the bar above the list.

The copy is named `<title> (copy)` and lands in the same folder. It has the content only, without comments, share links, or version history.

## Delete a folder

1. Click **⋯** at the end of the folder's row and select **Delete**.
2. In the confirmation, click **Delete**.

The folder and its subfolders are deleted. The documents inside them move back to the top of the workspace, so nothing is lost. A deleted folder can't be restored.

If your selection includes documents as well as a folder, the bar above the list shows **Delete**, and the selected documents go to the [Trash](/collaborate/trash).

## Find a document

- **Search**: type in **Search by title...** above the list.
- **Filter**: click **Type** and check the document types you want. Click **Clear filters** to show everything again.
- **Sort**: click a column heading.

## Known limitations

- Only documents you created, or any document if you own the workspace, can be dragged. To move a folder, use **Move to...**.
- A folder can't be shared or given its own permissions. Share each document instead.
- The **⋯** menu offers **Move to...** and **Delete** on every folder, but they fail with an error if you didn't create the folder and don't own the workspace.
- A document's **⋯** menu shows **Move to...** and **Move to Trash** only if you created it or own the workspace. In the bar above the list, **Move to…** and **Move to Trash** are grayed out when the selection includes a document you can't move.
