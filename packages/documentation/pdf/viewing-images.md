# Viewing Images

Wafflebase stores and displays **image files** alongside your sheets, docs,
slides, notes, and PDFs. Like a PDF, an image is a *view-only* document type —
you upload the original file and view it in the browser; the image itself is
never edited.

Supported formats are **PNG, JPEG, GIF, and WebP**, up to **25 MB** per file.

## Upload an image

1. Open your workspace
2. Click the **New** dropdown button
3. Select **Upload Image**
4. Choose an image file from your computer

The file uploads and opens in the viewer. It appears in your workspace document
list with a thumbnail, and its title defaults to the file name (which you can
rename).

::: tip
You can also **drag files straight onto the documents list** to upload several
at once — images, PDFs, spreadsheets, documents, and presentations are each
routed to the matching document type, and a panel in the bottom-right shows
per-file progress.
:::

## View an image

The viewer centers the image and fits it to your window. A toolbar lets you:

- **Zoom in / out** — step the zoom level up or down
- **Previous / Next** — jump to the previous or next image in the same
  workspace without returning to the list
- **Download** — save the original file back to your computer

A progress bar shows while the file downloads on first open.

## Rename an image

Click the title in the header to rename the document. The change is reflected in
your workspace list right away.

::: tip
Images are read-only. To change one, edit it elsewhere and upload the new
version.
:::
