# Keyboard shortcuts

Every keyboard shortcut in the note editor, for formatting, editing, finding text, and folding.

**Conventions.** Each entry lists the Mac key first, then Windows and Linux. Shortcuts work in the source pane, so click in it first. The note editor has no shortcut list of its own; point to a toolbar button to see its shortcut in the tooltip.

::: info Vim mode
With **Editor settings > Keyboard > Vim**, Vim's own keys apply. The formatting shortcuts below still work on a Mac but are off on Windows and Linux, where Vim uses those `Ctrl` keys. Undo is `u` and redo is `Ctrl+R`.
:::

## Most used

| To do this | Press |
|---|---|
| Bold | `⌘+B` / `Ctrl+B` |
| Italic | `⌘+I` / `Ctrl+I` |
| Add or remove a link | `⌘+K` / `Ctrl+K` |
| Undo | `⌘+Z` / `Ctrl+Z` |
| Redo | `⌘+Shift+Z` / `Ctrl+Shift+Z` or `Ctrl+Y` |
| Find and replace | `⌘+F` / `Ctrl+F` |

## Navigation

| To do this | Press |
|---|---|
| Next match (find panel) | `⌘+G` / `Ctrl+G`, or `Enter` in the find field |
| Previous match | `⌘+Shift+G` / `Ctrl+Shift+G` |
| Close the find panel | `Escape` |
| Go to a line number | `⌘+Option+G` / `Ctrl+Alt+G` |
| Start or end of the note | `⌘+↑` or `⌘+↓` / `Ctrl+Home` or `Ctrl+End` |
| Leave the editor | `Escape` |

`Escape` first closes the find panel or a suggestion list. Press it again to move focus out of the editor. In Vim mode it does not leave the editor.

## Selection

| To do this | Press |
|---|---|
| Select all | `⌘+A` / `Ctrl+A` |
| Select the current line | `Ctrl+L` / `Alt+L` |
| Select the next match of the selection | `⌘+D` / `Ctrl+D` |
| Select every match of the selection | `⌘+Shift+L` / `Ctrl+Shift+L` |
| Add a cursor above or below | `⌘+Option+↑` or `↓` / `Ctrl+Alt+↑` or `↓` |
| Add a cursor where you click | Hold `⌘` / `Ctrl` and click |
| Select a rectangle | Hold `Option` / `Alt` and drag |

## Editing

| To do this | Press |
|---|---|
| Indent the line or selection | `Tab` |
| Remove a level of indentation | `Shift+Tab` |
| Continue a list or quote on the next line | `Enter` |
| Move the line up or down | `Option+↑` or `↓` / `Alt+↑` or `↓` |
| Copy the line up or down | `Shift+Option+↑` or `↓` / `Shift+Alt+↑` or `↓` |
| Delete the line | `⌘+Shift+K` / `Ctrl+Shift+K` |
| Insert a blank line below | `⌘+Enter` / `Ctrl+Enter` |
| Copy, cut, paste | `⌘+C`, `⌘+X`, `⌘+V` / `Ctrl+C`, `Ctrl+X`, `Ctrl+V` |

`Tab` indents the text itself. To nest a list item one level, you can also click **Indent** in the toolbar.

## Formatting

| To do this | Press |
|---|---|
| Bold | `⌘+B` / `Ctrl+B` |
| Italic | `⌘+I` / `Ctrl+I` |
| Strikethrough | `⌘+Shift+X` / `Ctrl+Shift+X` |
| Add or remove a link | `⌘+K` / `Ctrl+K` |
| Numbered list | `⌘+Shift+7` / `Ctrl+Shift+7` |
| Bullet list | `⌘+Shift+8` / `Ctrl+Shift+8` |
| Checklist | `⌘+Shift+9` / `Ctrl+Shift+9` |
| Heading 1 to 6 | `⌘+Option+1` to `6` / `Ctrl+Alt+1` to `6` |
| Normal text | `⌘+Option+0` / `Ctrl+Alt+0` |

## View

| To do this | Press |
|---|---|
| Fold the heading or block at the cursor | `⌘+Option+[` / `Ctrl+Shift+[` |
| Unfold it | `⌘+Option+]` / `Ctrl+Shift+]` |
| Fold everything | `Ctrl+Option+[` / `Ctrl+Alt+[` |
| Unfold everything | `Ctrl+Option+]` / `Ctrl+Alt+]` |

You can also click the arrow in the gutter beside a heading or code block to fold it.
