# Notes

A note is a Markdown document you write with a live preview, together with your team in real time.

Use it to:

- Take meeting notes and checklists that everyone edits at once
- Draft runbooks, release notes, and specs with code blocks, tables, and diagrams
- Keep a shared scratchpad in plain Markdown, without page layout to manage

![Note in Split view with Markdown source on the left, rendered preview on the right, and the toolbar above](/images/notes/index-split-view.png)

## Get started

1. In your workspace, click **New**, then select **New note**. A note named **New Note** opens.
2. Type Markdown in the source pane, or use the toolbar to format text. See [Write and format](/notes/write-and-format).
3. Click **Share** in the top right to invite your team. See [Share a document](/collaborate/share).

Click the note's title in the header to rename it. Changes save automatically.

## On a phone

On a screen narrower than 768 pixels, a note has no Split view. One **Preview** button switches between the source and the rendered note. The toolbar keeps undo, redo, the text style, bold, and italic, and moves the rest into the ⋮ menu (**More formatting options**). See [Use Wafflebase on a phone](/start/phone).
