# Read and comment on PDFs

Read an uploaded PDF in the browser, copy its text, and discuss it with comments pinned to the page.

A PDF is view-only: you can't change its contents in Wafflebase. Comments sit over the page and never change the file.

::: info Before you start
- To add a PDF, [upload](/files/upload) a `.pdf` file of up to 50 MB.
- Anyone who can open the PDF can read it. To comment, you need to be a workspace member or have an **Editor** [share link](/collaborate/share).
:::

## Read a PDF

1. Open the PDF from your documents list.
2. Scroll to move through the pages.

The pages appear in one continuous column, each fitted to the width of the window up to a maximum width. A progress bar shows while the file loads. There is no zoom control; resize the window or collapse the sidebar to change the page width.

## Select and copy text

1. Drag across the text you want.
2. Press `⌘+C` / `Ctrl+C`.

To find a word, use your browser's find (`⌘+F` / `Ctrl+F`). It searches the pages you have already scrolled to.

A scanned page has no text to select. To comment on it, use [a region comment](#comment-on-a-region).

## Comment on selected text

1. Select the text you want to comment on.
2. Click **Comment** below the selection.
3. Type your comment. The selected text is quoted above the box.
4. Click **Comment** to post it.

The commented text stays highlighted until the thread is resolved, and the comment appears for everyone who has the PDF open.

![A sentence selected in a PDF with the Comment button below it](/images/files/pdfs-comment-on-text.png)

## Comment on a region

Use a region comment for a scanned page, a figure, or a table.

1. Click the speech-bubble icon with a plus (**Comment on a region**) in the header. The button is highlighted while the tool is on.
2. Drag a rectangle over the part of the page.
3. Type your comment and click **Comment**.

The comment is pinned to that area of that page. To cancel the tool before you drag, click the icon again.

## Reply to and resolve comments

1. Click the speech-bubble icon (**Show comments**) in the header.
2. Select a thread. The list labels each thread with its page, such as **Page 3**.
3. Reply, resolve or reopen the thread, or edit or delete your own comments.

The panel has **Open** and **Resolved** tabs, each with a count. Clicking a pin on the page opens its thread. For more about threads, see [Comments](/collaborate/comments).

![PDF with the comments panel open, listing two threads labeled Page 1 and Page 2](/images/files/pdfs-comments-panel.png)

## Download the original

Click the download icon (**Download PDF**) in the header. The original file downloads unchanged, without comments. Only people who can open the PDF can download it.

## See who else is reading

Avatars in the header show who else has the PDF open. They show who is reading, not which page they are on.

## Rename a PDF

Click the title in the header, type a new name, and press `Enter`.

## On a phone

The PDF fits the screen width, and the header keeps the same buttons. If the header is crowded, swipe the row of buttons sideways to reach the rest. See [Use Wafflebase on a phone](/start/phone).

## Known limitations

- There is no zoom, page navigation, or annotation tool. Comments are the only markup.
- A **Viewer** share link opens the PDF marked **View only**. Viewers can read comments but not add them.
- A share link page has no download button. To give someone the original file, send it to them separately.
- To change a PDF, edit it in another app and upload the new version.
- If a PDF fails to load, the viewer shows `Couldn't open this PDF. Reload the page to try again.`
