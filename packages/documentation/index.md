# Wafflebase

Wafflebase is a collaborative office suite for sheets, documents, presentations, notes, and boards that your team edits together in the browser.

Use it to:

- Build spreadsheets, write documents, and present slides without installing anything
- Edit the same document at the same time as your team, and see who is working where
- Share any document with a link, so people outside your workspace can view or edit it

![Workspace documents list with the sidebar and the New menu open](/images/start/overview-documents-list.png)

## Get started in 3 steps

1. **Create a document.** Sign in, click **New** above your documents list, and pick a type. See [Getting started](/start/getting-started).
2. **Edit it.** Changes save as you type. The header shows **Saved** once they reach the server.
3. **Share it.** Click **Share** in the top right of the editor, then **Create link**. See [Share a document](/collaborate/share).

## Choose an editor

| Editor | Use it for | Create it with |
|---|---|---|
| [Sheets](/sheets/) | Tables, formulas, charts, and pivot tables | **New > New sheet** |
| [Docs](/docs-editor/) | Paged documents with rich text, tables, and images | **New > New document** |
| [Slides](/slides/) | Presentations with themes, layouts, and animations | **New > New presentation** |
| [Notes](/notes/) | Markdown notes with a live preview | **New > New note** |
| [Board](/board/) | An infinite canvas for sticky notes, shapes, and drawing | **New > New board** |
| [Files](/files/upload) | PDFs, images, and any other file you upload | **New > Upload files…** |

To bring in existing work, use **New > Upload files…** or drag files onto the documents list. A `.xlsx`, `.csv`, `.docx`, or `.pptx` file becomes an editable document. See [Import and export](/files/import-export).

Inside a workspace, the **New** menu also has **New from template**, **New folder**, and **Import from Miro…**, which brings a Miro board in as a board.

## On a phone

Every editor opens on a phone. Comments, version history, and export move into the **⋮** (**More**) menu in the header. See [Use Wafflebase on a phone](/start/phone).
