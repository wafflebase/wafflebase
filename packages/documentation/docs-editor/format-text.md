# Format text

Style the words in a doc, set paragraph styles such as headings, and add links. Formatting changes apply to the selected text, or to what you type next if nothing is selected.

## Make text bold, italic, or underlined

1. Select the text.
2. Click **Bold**, **Italic**, or **Underline** in the toolbar, or press `⌘+B` / `Ctrl+B`, `⌘+I` / `Ctrl+I`, or `⌘+U` / `Ctrl+U`.

Click the button again to turn the style off.

### Strikethrough, superscript, and subscript

These have no toolbar button. Select the text and press:

- Strikethrough: `⌘+Shift+X` / `Ctrl+Shift+X`
- Superscript: `⌘+.` / `Ctrl+.`
- Subscript: `⌘+,` / `Ctrl+,`

## Change the font and size

1. Select the text.
2. Open the **Font** dropdown (it shows **Arial** in a new document) and select a font. Fonts you used recently are listed first under **Recent**.
3. To find another font, select **More fonts…**, search or filter the list, and select one.
4. In **Font size**, type a number and press `Enter`, or click **−** and **+**.

Sizes range from 1 to 400. A new document uses Arial 11.

![Fonts dialog with a search box and a filtered list of font families](/images/docs-editor/format-text-more-fonts.png)

## Change text and highlight color

1. Select the text.
2. Click **Text color** or **Highlight color** (marker icon) in the toolbar. Each button shows its current color.
3. Click a swatch.

To remove a color, open the same palette and click **Reset** (text color) or **None** (highlight).

## Copy formatting with Format painter

1. Put the cursor in text that has the formatting you want.
2. Click **Format painter** (brush icon) next to undo and redo. The button stays lit.
3. Select the text to restyle, then click **Format painter** again.

The selection takes on the copied formatting, and the button turns off. To cancel without applying, click the lit button with nothing selected.

::: tip
To paint several places in a row, use the keyboard: press `⌘+Shift+C` / `Ctrl+Shift+C` to copy the formatting, then select each target and press `⌘+Option+V` / `Ctrl+Alt+V`.
:::

## Clear formatting

1. Select the text.
2. Click **Clear formatting** in the toolbar, or press `⌘+\` / `Ctrl+\`.

Bold, italic, underline, strikethrough, fonts, sizes, and colors are removed. Links stay.

## Apply a heading or paragraph style

1. Put the cursor in the paragraph.
2. Open the **Styles** dropdown at the left of the toolbar and select a style: **Normal text**, **Title**, **Subtitle**, or **Heading 1** to **Heading 6**.

You can also type `#` to `######` and press `Space` at the start of an empty line to get Heading 1 to Heading 6, or press `⌘+Option+1` to `⌘+Option+6` / `Ctrl+Alt+1` to `Ctrl+Alt+6`. Pressing the shortcut for the heading a line already has turns it back into normal text.

## Redefine a style for this document

1. Format some text the way you want a style to look, for example a Heading 2 in a new color and font.
2. With the cursor in that text, open **Styles** and select **Options**.
3. Select **Update 'Heading 2' to match**. The menu names whichever style the cursor is in.

Every paragraph that uses the style updates. In the same **Options** menu:

- **Reset 'Heading 2'** puts that style back to its built-in look.
- **Reset styles** puts every style back.

![Styles dropdown open with the Options submenu showing Update to match and Reset items](/images/docs-editor/format-text-styles-options.png)

### Reuse your styles in other documents

1. In a document whose styles you like, open **Styles > Options** and select **Save as my default styles**.
2. In another document, open **Styles > Options** and select **Use my default styles**.

The saved styles belong to your account, so only you can apply them.

## Align paragraphs

1. Put the cursor in the paragraph, or select several.
2. Open **Text alignment** in the toolbar and select **Left**, **Center**, **Right**, or **Justify**.

The shortcuts are listed in the menu, for example `⌘+Shift+E` / `Ctrl+Shift+E` to center.

## Set line spacing

1. Put the cursor in the paragraph, or select several.
2. Open **Line spacing** in the toolbar and select **1.0**, **1.15**, **1.5**, or **2.0**.
3. For another value, select **Custom…**, type a number from 0.5 to 10, and press `Enter`.

## Add a link

1. Select the text to link.
2. Press `⌘+K` / `Ctrl+K`, click **Insert link** in the toolbar, or right-click and select **Add link**.
3. Type the address and click **Apply**, or press `Enter`.

If you skip `https://`, it is added for you. With nothing selected, the address itself is inserted as linked text.

A web address that starts with `http://` or `https://` also becomes a link when you type a space or press `Enter` after it.

### Edit, open, or remove a link

1. Click inside the link. A small box shows its address.
2. Click the address to open it in a new tab, click **Edit link** (pencil) to change it, or click **Remove link** to keep the text but drop the link.

People with view-only access see the address but not the edit and remove buttons.

## On a phone

The toolbar shows undo, redo, **Format painter**, **Bold**, **Italic**, **Underline**, both colors, and **Clear formatting**. Tap ⋮ (**More formatting options**) at the right end of the toolbar for:

- **Font**: the font and size pickers
- **Styles**: Normal text, Title, Subtitle, and headings (redefining styles needs a computer)
- **Insert > Link**
- **Align** and **Spacing** (line spacing)

## Known limitations

- Strikethrough, superscript, and subscript need a keyboard; there is no toolbar button.
- Paragraph spacing before and after a paragraph can't be set; use line spacing instead.
