# Write a project proposal

You will build a short project proposal with a title, section headings, a bulleted list, a budget table with a shaded header row, an image, a link, and a page number in the footer. It takes about 10 minutes.

::: info Before you start
- You need to be a member of a workspace.
- Use a computer. A few steps (the table size picker, the footer) are easier with a mouse.
- Have a PNG or JPEG image on hand, such as a logo or a chart.
:::

## 1. Create the document and add a title

1. In your workspace, click **New** and select **New document**.
2. Click the title in the header, type `Project proposal`, and press `Enter`.
3. Click the page and type `Website redesign proposal`.
4. Open the **Styles** dropdown at the left of the toolbar (it shows **Normal text**) and select **Title**.
5. Press `Enter` to start a new line. The new line is **Normal text** again.

## 2. Add sections and a list

1. Type `#` and press `Space`. The line becomes **Heading 1**.
2. Type `Goals` and press `Enter`.
3. Type `-` and press `Space` to start a bulleted list, then type these items, pressing `Enter` after each:

   ```text
   Cut page load time in half
   Make every page work on a phone
   Launch before the end of the quarter
   ```

4. Press `Enter` on the empty bullet to end the list.
5. Type `#`, press `Space`, type `Budget`, and press `Enter`.

You now have two Heading 1 sections. Headings show up as larger, bold text.

## 3. Insert and shade a budget table

1. Click the **Insert table** button (grid icon) in the toolbar.
2. Move the pointer over the grid until the label under it reads `4 x 3` (4 rows, 3 columns), then click.
3. Type the table below. Press `Tab` to move to the next cell.

   ```text
   Item          Owner   Cost
   Design        Alice   $12,000
   Development   Bob     $30,000
   Testing       Carol   $6,000
   ```

4. Drag from the first cell to the last cell of the top row to select the header row.
5. Right-click the selection, select **Cell background**, and click a light gray swatch.
6. Click below the table to leave it.

The header row is shaded and the costs line up in their own column.

## 4. Add an image and a link

1. Put the cursor on an empty line below the table.
2. Click **Insert image** (picture icon) and select **Upload from computer**, then choose your image.
3. Click the image and drag a corner handle to make it about half the page width.
4. Click after the image, press `Enter`, and type `See the current site for comparison.`
5. Select the words `current site`, press `⌘+K` / `Ctrl+K`, type `https://example.com`, and click **Apply**.

The words become a link. Put the cursor in them to see the address.

## 5. Number the pages and switch to A4

1. Scroll to the bottom of the page and double-click the margin below the text. The footer opens, and the toolbar narrows to footer controls.
2. Click **Page number** in the toolbar. A page number appears in the footer.
3. Press `Escape` to return to the body.
4. Click **Page setup** (page icon) at the right end of the toolbar.
5. Set **Paper size** to **A4** and click **Apply**.

## Check your work

Your proposal should look like this: a title, two headings, a list, a shaded table, an image, a link, and a page number at the bottom of the A4 page.

![Finished proposal with a title, Goals list, budget table with a gray header row, an image, and a footer page number](/images/docs-editor/write-a-proposal-final.png)

## What you learned

- Markdown-style shortcuts (`#` and `-` followed by `Space`) turn lines into headings and lists as you type.
- Tables take `Tab` to move between cells, and right-click for cell colors.
- Headers, footers, and page setup apply to the whole document.
