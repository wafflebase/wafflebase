# Insert and edit tables

Insert a table to lay out rows and columns, then change its structure and colors from the right-click menu.

## Insert a table

1. Put the cursor where the table should go.
2. Click **Insert table** (grid icon) in the toolbar.
3. Move the pointer over the grid to choose the size, up to 10 by 10, and click.

The table appears at the cursor, and the cursor moves into its first cell. To size the grid with the keyboard, use the arrow keys and press `Enter`.

![Insert table grid picker with a 4 by 3 area highlighted](/images/docs-editor/tables-grid-picker.png)

## Move between cells

- Press `Tab` to go to the next cell and `Shift+Tab` to go back.
- Press `Tab` in the last cell to add a new row.
- Click any cell to put the cursor there.

## Insert or delete rows and columns

1. Right-click a cell.
2. Under **Row**, select **Insert above**, **Insert below**, or **Delete row**.
3. Under **Column**, select **Insert left**, **Insert right**, or **Delete column**.

## Merge and unmerge cells

1. Drag across the cells to select a rectangle of them.
2. Right-click the selection and select **Merge cells**.

To split them again, right-click the merged cell and select **Unmerge cells**. Only merged cells can be split.

## Color a cell background

1. Click a cell, or drag to select several.
2. Right-click and select **Cell background**.
3. Click a swatch. To remove the color, select **Reset**.

![Table right-click menu with the Cell background swatches open](/images/docs-editor/tables-cell-background.png)

## Resize columns and rows

1. Point at a border between two columns or two rows. The pointer changes to a resize arrow.
2. Drag the border.

## Put a table inside a cell

1. Click inside a cell.
2. Click **Insert table** and choose a size.

The new table sits inside that cell and works like any other table.

## Delete a table

1. Right-click any cell in the table.
2. Select **Delete table**.

To undo, press `⌘+Z` / `Ctrl+Z`.

## Comment on text in a table

Select text in a cell, right-click, and select **Insert comment**. See [Comments](/collaborate/comments).

## On a phone

Tap ⋮ (**More formatting options**) at the right end of the toolbar and select **Table (3×3)** under **Insert**. A phone always inserts a 3 by 3 table; add rows with `Tab` in the last cell if you have a keyboard, or on a computer from the right-click menu.

## Known limitations

- A table taller than the rest of the page continues on the next page. The header row isn't repeated there.
- You can't insert a table in a header or footer.
- You can't insert a page break inside a table.
