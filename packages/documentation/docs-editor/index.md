# Docs

Docs is a page-based word processor where you write, format, and lay out documents with your team.

Use it to:

- Write reports, proposals, and specs that print and export as real pages
- Take meeting notes together, with everyone typing in the same document
- Review a draft with comments and restore an earlier version if needed

![Docs editor with the formatting toolbar, the ruler, and a page of a project proposal](/images/docs-editor/overview-toolbar.png)

## Get started

1. In your workspace, click **New** and select **New document**. A blank Letter-size page opens.
2. Click the title in the header to rename the document, then click the page and start typing. Use the toolbar to [format text](/docs-editor/format-text).
3. Click **Share** in the top right to invite people. See [Share a document](/collaborate/share).

To start from a ready-made layout instead, click **New** and select **New from template**. See [Templates](/collaborate/templates).

New to the editor? Follow [Write a project proposal](/docs-editor/write-a-proposal), which takes about 10 minutes.

## Write and format

- [Format text](/docs-editor/format-text): bold, fonts, colors, headings and styles, alignment, line spacing, and links
- [Lists and indents](/docs-editor/lists-and-indents): bulleted and numbered lists, nesting, and indents on the ruler
- [Paste from other apps](/docs-editor/paste-from-other-apps): what is kept when you paste from a web page, a spreadsheet, or another document

## Add tables and images

- [Tables](/docs-editor/tables): insert a table, add rows and columns, merge cells, and color cell backgrounds
- [Images](/docs-editor/images): upload, paste, or link an image, then resize it

## Lay out pages

- [Page layout](/docs-editor/page-layout): paper size, orientation, margins, page breaks, horizontal lines, headers, footers, and page numbers

## Review and finish

- [Find and spelling](/docs-editor/find-and-spelling): find and replace text and fix misspelled words
- [Comments](/collaborate/comments): select text and press `⌘+Option+M` / `Ctrl+Alt+M` to start a thread
- [Version history](/collaborate/version-history): see and restore earlier versions
- [Import and export](/files/import-export): open a Word file, or download as Word (.docx), PDF (.pdf), Markdown (.md), or Plain text (.txt) from the **Export** (download icon) menu in the header

## On a phone

You can write and format on a phone. The toolbar keeps undo, redo, **Format painter**, bold, italic, underline, colors, and **Clear formatting**; on a narrow screen, swipe the toolbar sideways to reach the colors and **Clear formatting**. Everything else is in the ⋮ menu at the right end of the toolbar (**More formatting options**), which stays in view. Comments, version history, and export move to the header's **More** menu. The ruler is hidden, and find, replace, and keyboard shortcuts need a hardware keyboard. See [Use Wafflebase on a phone](/start/phone).
