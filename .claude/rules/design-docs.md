# Design docs

- New design doc: start from `docs/design/TEMPLATE.md` (frontmatter `title` + `target-version`), then add its row to the matching table in `docs/design/README.md`.
- File docs by validity; there is no archive folder.
- Fold a still-valid single-PR note into its canonical subsystem doc.
- Delete a superseded doc and leave a one-line pointer in its successor and in the commit message.
