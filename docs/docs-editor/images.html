Add and edit images ​

Add pictures to a doc and size them to fit your layout. Images sit in the line of text, like a large character.

Before you start

  • You need edit access to the document.
  • Uploads: PNG, JPEG, GIF, or WebP, up to 10 MB each.
  • An image added by URL keeps loading from its original site. If that site removes it, it disappears from your doc.

Upload an image ​

  1. Put the cursor where the image should go.
  2. Click Insert image (picture icon) in the toolbar and select Upload from computer.
  3. Choose the image file.

The image appears at the cursor. A wide image is scaled down to fit between the margins.

Drag or paste an image ​

  • Drag an image file from your computer onto the page.
  • Copy an image or take a screenshot in another app, then press ⌘+V / Ctrl+V in the doc.

Add an image by URL ​

  1. Click Insert image and select By URL….
  2. Paste the image address. It must start with http:// or https://.
  3. Click Insert.

If the image can't be loaded, the box stays open so you can fix the address.

Resize an image ​

  1. Click the image. Eight square handles appear around it.
  2. Drag a corner handle to resize it and keep its proportions. Hold Shift while dragging to resize freely.
  3. Drag a side handle to stretch only the width or the height.

While you drag, a label shows the new width and height in pixels.

Copy, cut, or delete an image ​

  1. Click the image to select it.
  2. Press ⌘+C / Ctrl+C to copy, ⌘+X / Ctrl+X to cut, or Delete / Backspace to remove it.

Paste a copied image anywhere in the same or another doc. To replace an image, delete it and insert the new one.

Move the cursor around an image ​

With an image selected:

  • Escape deselects it and puts the cursor next to it.
  • ← puts the cursor just before the image, and → just after it.
  • ↑ and ↓ move the cursor up or down a line.

To move an image, cut it and paste it at the new spot.

On a phone ​

Tap ⋮ (More formatting options) at the right end of the toolbar and select Image under Insert to upload a photo. Adding an image by URL needs a computer.

Known limitations ​

  • You can't crop or rotate an image in the editor, or wrap text around it.
  • Images can't be added to a header or footer from the toolbar.

Related ​

  • Paste from other apps for what happens to images in pasted web content.
  • Page layout to widen the space between margins.
  • Troubleshooting if you see "Couldn't upload the image" or "Image URL must start with http:// or https://".
