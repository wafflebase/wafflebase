Set up pages, headers, and footers ​

Set up the pages of a doc and add text that repeats on every page. A new document uses Letter paper, portrait, with 1-inch margins. What you see on screen is how the pages print and export to PDF.

Change paper size and orientation ​

  1. Click Page setup (page icon) at the right end of the toolbar.
  2. Under Paper size, select Letter, A4, or Legal.
  3. Under Orientation, select Portrait or Landscape.
  4. Click Apply.

The change applies to every page, and one undo reverts it. A Word file with another paper size shows it as Custom (name); pick a listed size to change it.

Change margins ​

  1. Click Page setup.
  2. Under Margins (inches), enter Top, Bottom, Left, and Right.
  3. Click Apply.

Margins must be zero or more and leave room for text. If they don't, the dialog says so and Apply stays off.

Drag margins on the ruler ​

Drag the edge of the shaded area on the ruler above the page to change the left or right margin. Drag the edge on the ruler at the left side to change the top or bottom margin.

Insert a page break ​

  1. Put the cursor where the next page should start.
  2. Press ⌘+Enter / Ctrl+Enter.

Everything after the cursor moves to the top of the next page. Long paragraphs and tables also flow onto the next page on their own.

Add a horizontal line ​

  1. On an empty line in the body, type ---.
  2. Press Enter.

A horizontal line replaces the three dashes, and the cursor moves to a new line below it.

Add a header or footer ​

  1. Double-click the top margin of any page for the header, or the bottom margin for the footer.
  2. Type the text. The toolbar narrows to Font, Font size, Bold, Italic, Underline, colors, Text alignment, and Page number.
  3. Press Escape, or click the page body, to go back to the body.

The same header and footer appear on every page.

Add page numbers ​

  1. Double-click the header or footer area to edit it.
  2. Put the cursor where the number should go, and use Text alignment to place it left, center, or right.
  3. Click Page number in the toolbar.

Each page shows its own number, and the numbers update as pages are added or removed.

On a phone ​

Tap ⋮ (More formatting options) at the right end of the toolbar and select Page setup under Document. The ruler is hidden on a phone, so set margins in the dialog.

Known limitations ​

  • There is one header and one footer for the whole document. You can't use a different first page.
  • You can't add a table or a page break to a header or footer. The narrow toolbar has no list, link, image, or style controls.
  • A table in the header or footer of an imported Word file is shown, and you can edit the text in its cells, but you can't add or remove its rows or columns.
  • Margins are set in inches, even when the ruler shows centimeters.
