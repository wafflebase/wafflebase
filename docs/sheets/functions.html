Function reference ​

Every function you can use in a Sheets formula, grouped by category, with its syntax and a short description.

Conventions. Arguments in square brackets, such as [if_not_found], are optional. , ... means you can repeat the argument. Function names are not case-sensitive.

In the app. Click Functions in the toolbar to search this list and insert a function into a cell. On a phone, it is in the ⋮ (More formatting options) menu. For how to enter formulas, see Formulas.

CategoryCovers
DateDates, times, and working days
EngineeringNumber bases, bitwise operations, and complex numbers
FinancialLoans, investments, depreciation, and securities
InfoChecking the type of a value or cell
LogicalConditions and branching
LookupFinding values and reshaping ranges
MathArithmetic, rounding, and trigonometry
OperatorFunction forms of operators such as +, =, and &
StatisticalAverages, counts, distributions, and tests
TextJoining, splitting, searching, and changing text
DatabaseCalculations over a table that match criteria

INFO

FILTER, UNIQUE, SEQUENCE, SORTBY, VSTACK, TAKE, DROP, TOCOL, FLATTEN, and SPLIT return only their first value, not a whole range. See Return several values at once.
