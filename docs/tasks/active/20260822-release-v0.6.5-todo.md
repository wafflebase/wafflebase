# Release v0.6.5

Close out the v0.6.5 release covering the `v0.6.4..HEAD` window (137
commits, 10 authors). Theme: **sheets learns to read the lakehouse,
the app grows in-app notifications and document copies, and the design
editor turns from a scaffold into a working three-pane editor**.

**Patch (not minor) bump.** The window's largest additions are the
Lakehouse (#868) and BigQuery (#811) connectors and in-app notifications
(#764). All three extend existing surfaces — a new tab type inside
sheets, a new backend module, a header bell — and none adds a document
type. The standing convention reserves a minor for a new document type
plus package, so this stays a patch, consistent with v0.6.3 scoping the
`file` document type as one.

## Highlights

### Security

- **Formula reference XSS fixed** (#763). Worth calling out first in the
  release notes; it is the only security-relevant change in the window.

### Product — Sheets

- **Lakehouse connector** (#868): Iceberg and Delta Lake tables read
  straight from object storage through an embedded DuckDB, with a
  time-travel slider over commit history. S3, GCS-interop, Azure and
  local filesystem backends; the DuckDB extensions are baked into the
  backend image at build time so a deployment needs no egress to
  `extensions.duckdb.org`.
- **BigQuery connector** (#811): connection CRUD and read-only query
  execution. Backend only this window — no BigQuery UI yet.
- **Date display format setting and date-cell tooltips** (#809).
- **Sheet CRDT root initialized on v1 write paths** (#900), so a
  document created through the REST API is not missing its root.

### Product — Docs

- **Bold / italic / underline / strikethrough toggle from the selection
  rather than the caret** (#757) — the long-standing mismatch with
  Google Docs behaviour.
- Font-color reset no longer paints the selection color (#810), the Text
  style control refreshes after a block type is applied (#864), an image
  pasted next to another is no longer merged away (#865), and clearing a
  highlight stores no color instead of an empty one (#867).

### Product — Slides, Notes, Documents

- **Slides**: toolbar focus returns to the canvas after use (#899).
- **Notes**: image upload in the markdown editor (#842); an oversized
  image is downscaled instead of refused (#856).
- **Documents**: **"Make a copy"** duplicates a document server-side
  (#812).
- **In-app notifications** (#764): header bell, unread badge, Postgres
  rows and an SSE stream. Comment mentions/replies/resolves are
  client-reported and server-authorized; multi-replica safe with no new
  infrastructure.

### Collaboration

- **Yorkie JS SDK** 0.7.14 → 0.7.15 (#841) → 0.7.16 (#859) → 0.7.17
  (#919). The last of those carries a GC accounting fix — a removed
  container's descendants are now counted in the GC total — which is
  load-bearing here because this repo's 10 MB document ceiling is bound
  by CRDT node count rather than bytes.

### CLI

- Failures classified so system errors exit 2 (#648); parse errors route
  through the JSON error envelope (#768); `status` and `ctx list` route
  through the output formatter (#695); upstream error bodies are
  validated before being forwarded (#770) and upstream error text is
  never published, with tokens masked by shape (#857).

### Design editor (dev-only, private package)

The window's largest single effort. It went from a scaffold to something
that runs: the AST mutator completed (#776, #777), the plugin host over a
configurable root (#819), the `TokenAdapter` seam (#833), design-sandbox
as wafflebase's own adapter (#839), the bridge client (#846), the
staged-edit model (#848), the frame layer (#855), a served shell (#879)
grown into a three-pane scene editor (#887), wafflebase's own scenes
mounted (#891) and canvas scenes rendered (#903), token panels routed
through a review (#896), and a real class edited against wafflebase's
own source (#907). Nothing user-facing.

### CI / build

- **Merge queue enabled** (#755 triggers CI on `merge_group`).
- **Path-aware CI** (#803, #807): only the CI a change can affect runs,
  with deploys gated on full CI.
- Documentation graph gated against dead links (#861) and the repository
  index files against what is on disk (#821).

### Agent / review pipeline & eval harness (dev infrastructure)

Again the bulk of the window, and not user-facing. The pipeline moved
out to `wafflebase/agent-pipeline` (#769) and back (#850); a credential
pool now spreads work across slots with failover (#854, #858, #894,
#910). The eval harness gained scorers for volume/mix (#773),
complementarity (#779), reliability (#782), cost/latency (#791),
segmentation (#808) and validity (#905), a free scoring lane (#834), an
adjudication CLI (#817), a comparison report (#805) with cost/latency
(#828), pair-label (#902), segmentation (#909) and validity (#908)
sections, and cross-run scores keyed by a `panel_digest` (#915).

### Docs / tasks

- **Task archive**: 49 completed tasks archived (65 active → 16). Two had
  shipped without their boxes ticked (the merge queue, and v0.6.4's own
  devops image pin). The larger finding was structural: 64 boxes across
  23 files were negative-form disclosures ("Not verified: …", "Not run:
  …") that could never be ticked, so their tasks could never archive.
  Converted to plain bullets. See
  `20260822-task-archive-audit-lessons.md`.
