# Release v0.6.14

**Created**: 2026-11-08

Cut `v0.6.14`. What drives it is the CodePair → Wafflebase migration: the
workspace claims (#1118) must be live in production before the migrated,
owner-less CodePair workspaces can be handed to their GitHub owners and
CodePair can be shut down. The rest of the window rides along.

## Preconditions

- [x] **Production Yorkie is at least v0.7.26.** #1117 says the 0.7.26 SDK
      writes the Text undo removal ledger and needs a v0.7.26 server.
      `kubectl -n yorkie get deploy` reports `yorkieteam/yorkie:0.7.27-rc`
      (checked 2026-11-08).
- [x] **No backend change that needs a matching frontend, and no frontend
      change that needs this backend.** `v0.6.13..main` touches
      `packages/backend` through #1118 (claims; sign-in only), #1108 (slides
      meta in backend root I/O), #1090 / #1109 (template seed and slide lint
      tooling) and the SDK bump #1117. The frontend changes (#1113 title live
      sync, #1116 row auto-fit, #1107 / #1111 / #1110) need no new route.
- [x] **The new migration is additive.** `20261108120000_add_workspace_claim`
      only creates `WorkspaceClaim`; the `prisma-migrate` init container
      applies it on rollout.
