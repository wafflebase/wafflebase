# Release v0.6.3

Close out the v0.6.3 release covering the `v0.6.2..HEAD` window (66
commits). Theme: **a generic `file` document type + the Board matured from
an SP1 skeleton into a usable surface + continued agent/review pipeline
build-out**.

**Patch (not minor) bump** — decided by the maintainer, consistent with the
v0.6.2 precedent. This window does add one new document type (`file`,
#698), which the standing convention (minor-reserved-for-new-doc-type-+-
package) would weigh toward a minor. It ships no new package, and `file` is
explicitly "a blob with no dedicated viewer" reusing the type-agnostic
`Document.fileId` spine — a thinner addition than the `image` + `board`
pair that v0.6.2 already scoped as a patch. Recorded here as a deliberate
convention call, not an oversight.

## Highlights

### Product

- **Generic file upload** (#698): any file is now storable as a `"file"`
  document. `Document.type` is defined as a viewer-routing key; the upload
  allow-list is replaced by a **serving** rule (response `Content-Type`
  derived from document type, `file` always `attachment` + octet-stream),
  plus `fileSize`/`mimeType` columns. Also fixes image/file share links
  falling through to a `sheet-<id>` Yorkie doc, and deletes the upload
  queue's `skipped` path.
- **CLI file upload/download** (#703): `wafflebase` can upload and download
  any file, backed by new `POST/GET /api/v1/workspaces/:wid/files`
  endpoints sharing `fileResponseHeaders()` with the web serving path.
- **Board SP2** (#619): sticky notes (a preset `roundRect` with
  shrink-autofit text), image paste/drop/file-picker, and a view-local
  minimap — all board-local, zero CRDT-schema change.
- **Board SP3** (#622): structured Miro board import via Miro REST v2. The
  caller's access token is used backend-only for one request and never
  stored or logged; images are re-hosted into the workspace bucket;
  unsupported items are reported rather than dropped. Follow-up added a
  bounded-concurrency image pool and NDJSON progress streaming.
- **Board SP4** (#685): the board toolbar was insert-only, so nothing
  placed could be restyled. Composes the shipped slides leaf controls into
  a morphing idle/object/text-edit toolbar, plus board zoom/fit, select-all,
  and peer cursors.
- **Notes**: undo/redo moved onto Yorkie `doc.history` (#605) with caret
  preserved across undo/redo (#653).
- **Docs**: relative font-size stepping over a mixed selection (#616) —
  an 11pt run becomes 12pt and a 36pt run 37pt in the same click; IME undo
  caret race against the live-cursor publisher (#612).
- **Platform**: documents-list checkbox hit area widened to 32x32 (#623),
  pluralized Note/PDF type-filter labels (#627).

### Security / infrastructure

- **Dependabot**: 35 of 39 alerts cleared across both lockfiles (#679); the
  docs-site vite moved to 6.4.3 to clear the last 3 (#697).
- **GitHub Pages**: docs assets pruned so the deploy stops hitting its
  timeout (#702), then the manifest guarded and the real root cause
  corrected (#704).
- **CLI**: schema output fixed for row-oriented formats (#705);
  `import --replace --dry-run` no longer trips the confirm gate (#652).

### Agent / review pipeline & harness (dev infrastructure)

The bulk of the window, as in v0.6.2. Not user-facing; degrades to a no-op
without the pipeline configured.

- **Review panel**: starts when CI starts rather than when it finishes
  (#651), one panel per branch (#649), per-lens reasoning effort (#636),
  in-progress lens display (#638), a three-round fix-loop cap (#615), and
  `@claude fix` / `@claude rerun` on-demand entry points (#672, #650,
  #666, #631, #663).
- **Findings quality**: authors can dispute a finding and the panel decides
  (#633), lens stamping so rebuttals can be matched (#674), CodeRabbit
  attribution (#646), re-found priors verified once (#645), resolvable-path
  requirements (#637), and infra/quota errors kept out of the next round
  (#639).
- **Observability**: per-lens stage-detail capture as an artifact (#641,
  #664, #673, #644, #668, #675, #676), a session ledger and run links
  (#688), Phase 1 pipeline observability (#681), real wall-clock reporting
  (#669), and a visible dispute channel with dead-kickoff reporting (#690).
- **Eval harness**: freeze a PR into a replayable corpus item (#677) and
  replay it through the panel (#682); full lens-config hashing (#680).
- **UI hunter**: browser executor, harness and free oracles (#642), a
  prediction protocol where the model proposes and code decides (#665), a
  live session with one MCP tool (#678), and an orchestrator (#684).
- **Hygiene**: `scripts/` linted for the first time (#658), probes kept out
  of production (#656), own-comment-only ledger sweeps (#683).
