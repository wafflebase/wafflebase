# TODO — Refresh the repository index files and gate them

Index files (`packages/README.md`, the root `README.md` package list,
`docs/design/README.md`, `scripts/README.md`) are hand-maintained tables of
contents. Nothing checks them, so they drift silently: a new package ships and
the index that is supposed to introduce it never learns about it.

## Measured drift (2026-08-13, at `96ff6f2be`)

| Index | State |
| ----- | ----- |
| `packages/README.md` | 4 of 11 packages missing (`board`, `core`, `notes`, `design-editor`); `cli` described as a "Go CLI" when it is TypeScript (tsup → `dist/bin.js`) |
| root `README.md` | Same list, same 4 missing |
| `docs/design/README.md` | Accurate — 105 links, 0 dead, the 4 unlinked files under `docs/tables/` are covered by the umbrella row's directory link |
| `scripts/README.md` | Does not exist; `scripts/` holds 19 top-level scripts plus `agent/`, `hooks/`, `test/` |
| `packages/design-editor/README.md` | Does not exist (the only package without one) |
| `docs/tasks/README.md` | Generated by `scripts/tasks-index.mjs` — out of scope, never hand-edited |

## Approach

Two halves: correct the content once, then gate the *coverage* direction so it
cannot silently rot again.

`verify:entropy` already walks links → disk (`runDocStaleness` reports a dead
ref in any top-level `docs/design/*.md`). The new check is the complement —
disk → index — so the two do not overlap.
