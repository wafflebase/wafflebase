# Release v0.6.4

Close out the v0.6.4 release covering the `v0.6.3..HEAD` window (46
commits, 12 authors). Theme: **sheets gains the rest of its client-side
import formats, the Board's grid becomes a real editing aid, the backend
learns GitHub Enterprise, and the review/eval pipeline turns its first
real corpus replay**.

**Patch (not minor) bump** — decided by the maintainer. The window adds a
new package, `@wafflebase/design-editor` (#717, #718), which the standing
convention (minor-reserved-for-new-doc-type-+-package) would weigh toward
a minor. It is **private and dev-only** — a Vite-plugin scaffold plus a
shared JSX node model, published nowhere, reachable by no user, and
adding no document type. That is a thinner addition than the `file`
document type v0.6.3 already scoped as a patch. Recorded here as a
deliberate convention call, not an oversight.

## Highlights

### Product

- **Sheets file import completes its client-side set**: CSV / TSV (#670)
  and JSON (#724) join the `.xlsx` path, so the three formats a user is
  most likely to have on disk now import without a backend round trip.
- **Sheets formulas**: `INDEX` over `HSTACK`, `CHOOSECOLS` and `SORT`
  arrays (#735) — array-producing functions were not addressable by
  `INDEX`.
- **Notes**: Mermaid diagrams render in the markdown preview (#632).
- **Board**: a Miro-style background grid (#722) and move/resize snapping
  onto that visible grid (#731), so placement is finally predictable;
  Miro import resolves parent-relative positions (#710), fixing frame
  children landing at the wrong coordinates.
- **Files**: blob titles keep their extension and upload into the current
  folder (#709).
- **Datasources**: a connection can be tested before it is saved (#699).
- **Permissions**: owner-only workspace settings controls are hidden from
  members (#734) and the analytics Details link from non-managers (#737).
- **Yorkie JS SDK** to 0.7.14 (#730).

### Backend / deployment

- **GitHub Enterprise login** (#744, #751): the four OAuth endpoints are
  configurable, and the user-email endpoint is separate because a GHE
  token fails against `api.github.com` with "Bad credentials". A GHE
  instance can now be the identity provider.
- **Optional storage key prefix** (#720): wafflebase's objects can be
  namespaced inside a bucket shared with another app.

### REST API / CLI

- Tab **create and rename** across the REST API and CLI (#708).
- **YAML output** (#729).
- `--quiet` keeps the result body and the error envelope (#694) — it now
  suppresses progress notices only.

### Design editor (new, dev-only)

- `@wafflebase/design-editor` scaffolded with a parameterized CSS emitter
  (#717) and `jsx-nodes`, the shared JSX node model (#718); the docs moved
  under `docs/design/` and the local-plugin pivot is recorded (#701).
  Private package, nothing user-facing this window.

### Build / tooling

- Engine declarations are emitted with `tsc` instead of api-extractor
  (#753).
- `.nvmrc` so `nvm use` selects the required Node version (#723).
- `ci.yml`'s three jobs carry `timeout-minutes` and the `agent:tests` lane
  is bounded (#692); that lane also stopped silently dropping test files
  (#750).

### Agent / review pipeline & harness (dev infrastructure)

The bulk of the window again. Not user-facing; degrades to a no-op
without the pipeline configured.

- **Panel output**: findings post into the PR conversation (#745) in a
  triage layout (#693); the round table became a map that says what the
  fixer did (#746); disputes report both when nothing was disputed and how
  they went (#747); fix rounds are counted as run (#742); the rerun floor
  resolves by permission rather than `author_association` (#686);
  adjudicated copies persist so the standstill bound can count (#689); and
  dedupe stopped discarding a second finding with no record (#748).
- **CodeRabbit arm**: all four comment formats plus the review body are
  read (#714), blockquote markers are stripped first (#719), and the
  comments map into the normalised finding record (#739).
- **Eval harness**: a normalised finding record derived from the panel's
  runs (#713); `localization_scope` in a corpus item's meta (#687); replay
  against a git worktree at the review commit with a spawn timeout and a
  required cost cap (#716); `--review-commit` pinning (#752); a
  `workflow_dispatch`-only CI replay lane (#740); the determinism gate no
  longer scores a replay that never ran (#691); a seeded run passes by
  being refuted (#712); the stub panel's processes are reaped (#760).
- **UI hunter**: refuses a scrolled-away cell instead of handing back a
  dead click point (#736); the docs explorer toggles a control twice
  rather than once (#741).

### Docs / tasks

- **Task archive**: 26 completed tasks archived across two passes. Ten had
  shipped without their boxes ever being ticked; five more were "shipped
  but never verified in production", and checking GitHub directly closed
  them — the stage-detail capture is confirmed from both producers with a
  90-day expiry GitHub did not clamp, the CI timeouts have ~100 runs with
  no `timed_out`, and the finding record now has its assertion against
  real model output (142 records from the `pilot-01__k1` reviewer replay).
  Active tasks: 31 -> 18, plus this release task = 19.
