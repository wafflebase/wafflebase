# Release v0.6.2

Close out the v0.6.2 release covering the `v0.6.1..HEAD` window (92
commits). Theme: **autonomous agent/review pipeline build-out + new
`image` and `board` document types + Docs/Sheets/Notes editor polish**.

**Patch (not minor) bump** — decided by the maintainer. This window does
add two new document types (`image` #499, `board` SP1 #606, plus the new
`@wafflebase/board` package), which the standing convention
(minor-reserved-for-new-doc-type-+-package) would read as a minor. The
maintainer scoped it as a patch: `board` ships only as an SP1 canvas
skeleton and `image` is a thin static-blob viewer reusing the PDF spine,
so neither is treated as a headline new-surface release. Recorded here as
a deliberate convention override, not an oversight.

## Highlights

### Product

- **Image documents** (#499): new `image` document type — upload / static
  `<img>` viewer with zoom + download, list thumbnails, joins the
  multi-file upload queue; reuses the PDF blob spine.
- **Board (infinite canvas) SP1** (#606): new `board` document type + new
  `@wafflebase/board` package — canvas skeleton (shapes / text /
  connectors + collaboration) reusing the Slides scene engine via a
  viewport injection; "New Board" entry, `board-<id>` docKey.
- **Workspace folders** (#500, #502, #535): arbitrary-depth folder tree
  scoped to a workspace, folders as rows in the list, upload into the
  current folder, non-destructive delete.
- **Documents bulk select + move** (#503): multi-select, action bar, bulk
  move/delete, drag-and-drop onto folders/breadcrumbs.
- **Analytics dashboard viz** (#497): trend chart + date-range picker over
  the Share Link analytics warehouse.
- **Sheets**: whole-column / whole-row / open-ended range references
  (#521, #556), ECMA byte-oriented text functions (#513), auto-linked URL
  cells (#547), compact xlsx style import via maximal-rectangle tiling
  (#506).
- **Docs**: mixed-size baseline alignment (#507, #515), selection restore
  on undo/redo (#523), hyperlink polish across Docs/Slides text + tables
  (#520, #532, #580), nest a pasted table into the caret's cell (#531),
  IME composing underline (#514), read-mode select/copy/link in the
  viewer (#548), DOCX `w:sdt` text import (#504).
- **Notes**: `<details>`/`<summary>` collapsible sections (#544), empty
  nested bullet fix (#549), code-block styling + copy button (#533), Tab
  indent + toolbar undo/redo (#505).
- **Platform**: sortable Created column (#546), PDF/file download buttons
  (#536), unified toolbar dropdowns across editors (#498), Yorkie JS SDK
  bump to 0.7.13 (#534).

### Agent / review pipeline & harness (dev infrastructure)

The bulk of the window. Not user-facing; degrades to a no-op without the
pipeline configured.

- **Autonomous issue → PR pipeline** (#501) and a **local Spec → PR front
  door** (#559); OAuth-token auth (#509), turn-budget + draft-early
  landing (#510, #512).
- **Review panel**: one orchestrator + reviewer subagents (#508),
  coverage-first rubrics (#574), path-scoped lenses (#564), incremental
  review (#581, #590), independent grounded verifier (#573), blast-radius
  lens (#576), restatement clustering (#591, #601), effort/cost +
  per-lens token attribution (#522, #565, #603), reliability signals
  (#568), sample/cost tuning (#594, #607, #610, #611).
- **Autonomous issue hunting** (#587, #588, #600, #602) behind grants /
  workspace refusal; move the pipeline to Claude Opus 5 (#571); raise the
  verifier's presence turn ceiling 8 → 20 (#614).
