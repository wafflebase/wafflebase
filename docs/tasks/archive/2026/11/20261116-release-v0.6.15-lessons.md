# Lessons — release v0.6.15

- A frontend-only deploy can turn a backend route's *meaning* stale, not
  just make a route 404. #1141 kept `DELETE /documents/:id` and changed it
  from "destroy" to "move to trash" on the backend side; the frontend that
  says "Move to Trash" shipped first, so against the old backend the same
  request destroyed documents the UI promised were recoverable. When a PR
  changes what an existing endpoint *does*, treat the backend rollout as part
  of merging it.
