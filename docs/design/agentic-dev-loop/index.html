발표할 때

  • 덱은 ← → 또는 Space로 넘어갑니다. 그냥 스크롤해서 읽어도 됩니다.
  • 브라우저 전체화면(F11)이면 슬라이드처럼 보입니다. 우측 하단에 현재 장 번호가 있습니다.

페이지 서빙

# 저장소 루트에서 — 나만 볼 때
python3 -m http.server 8080
→ http://localhost:8080/docs/design/agentic-dev-loop/

# 세션 참석자들이 같은 네트워크에서 열어야 할 때
python3 -m http.server 8080 --bind 0.0.0.0
→ http://<내 IP>:8080/docs/design/agentic-dev-loop/   (hostname -I 로 IP 확인)

파일을 그냥 더블클릭해 file://로 열어도 동작합니다.
다만 링크 공유와 폰트 캐시 때문에 서버로 띄우는 쪽이 편합니다.

실습 전에 참석자에게 미리 안내할 것

  • Node 22 이상과 git, 그리고 git config user.name / user.email (커밋을 하기 위함)
  • 저장소를 클론(복사가 아니라)해 둘 것 — origin이 없으면 PR 단계에서 멈춥니다.
  • pnpm design을 세션 전에 한 번 실행해 볼 것.
    첫 설치 약 2분, WSL2에서는 첫 씬 로드가 1분 가까이 걸립니다.
    미리 해 오면 세션에서 기다릴 일이 없습니다.
  • pnpm · Docker · 데이터베이스 · GitHub CLI는 필요 없습니다.
